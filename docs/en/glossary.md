# Terms explained

[Nederlands](../nl/begrippen.md) · [Documentation](README.md)

| Term | Meaning in ProxyPermit |
| --- | --- |
| Proxy / Tinyproxy | The service that forwards requests from client devices to websites. Tinyproxy processes the traffic; ProxyPermit manages its settings. |
| Management console | The web interface where administrators change rules and settings. It has its own address and login. |
| Client | A device or program configured to send requests through the proxy. |
| Client access rule / ACL | A rule deciding which source devices may use the proxy. This is separate from destination filtering. |
| Destination filter | A rule matching a website or domain requested through the proxy. |
| Allowlist / blocklist | Permit matching destinations and block the rest / block matching destinations and permit the rest. |
| Draft / active configuration | Saved work awaiting publication / the configuration Tinyproxy is currently using. |
| Publish | Apply the reviewed configuration. On paired HA, publish shared policy on A so B can receive it. |
| Node | One server running ProxyPermit and Tinyproxy. |
| HA / failover | High availability / automatic takeover by the other server when the health check fails. |
| VIP | Virtual IP: the shared proxy address held by one HA node at a time. Clients keep using that address during takeover. |
| Keepalived / VRRP | The service and network protocol used to move the VIP between nodes. |
| Policy / revision | The shared rules and supported Tinyproxy settings / an identifier used to compare versions of that policy. |
| Synchronization | B automatically fetching and applying published policy from A. This does not copy local accounts. |
| CIDR / prefix | A network address with its size, such as `192.0.2.0/24`. A single IPv4 host uses `/32`. Use the actual trusted network, not an example. |
| UFW | The host firewall used for managed network access rules. |
| Anti-lockout | A profile pinned by an OS administrator to preserve configured management and proxy network access. Destination filters still apply. |
| 2FA / TOTP | An extra sign-in code, usually six digits, generated by an authenticator app. Optional for each account. |
| Audit log / retention | A record of who changed what / the maximum period records are kept, subject to storage limits. |
| SSH / SSH tunnel | An encrypted management connection / forwarding a local port through that connection so your browser can reach the private console. |
| HTTPS / TLS certificate | An encrypted web connection / a certificate that helps verify the server you are connecting to. It does not replace sign-in. |
| CONNECT | The proxy request used to create a tunnel, commonly for HTTPS. Tinyproxy can filter its destination but cannot read the encrypted page paths. |
| root / sudo | The OS administrator account / a way to run an authorized command with administrator privileges. Review the plan before applying changes. |
| NAT / management source | Address translation / the source address seen by the server. Several independent VM connections can show the same NAT source; it is not the node’s own address. |
| Session | Your signed-in browser state. A role or password change can invalidate it and require a new sign-in. |

For a practical explanation of two-server operation, see [High availability](high-availability.md).
