## Which version? / Welke versie?

These guides follow the `main` branch. New work can appear here before a release.
Check your installed version before following a procedure; see the repository's
[release notes](https://github.com/Dantdmnl/ProxyPermit/blob/main/CHANGELOG.md).

Deze handleidingen volgen de `main`-branch. Nieuwe functies kunnen hier staan
voordat ze zijn uitgebracht. Controleer je geïnstalleerde versie en lees de
[releaseopmerkingen](https://github.com/Dantdmnl/ProxyPermit/blob/main/CHANGELOG.md).

Historical instructions remain in the
[archive / archief](https://github.com/Dantdmnl/ProxyPermit/tree/main/docs/legacy).
Use them only for the older deployment they describe.
